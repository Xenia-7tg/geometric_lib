## Общее описание решения

**Geometric_lib** - это открытая библиотака, написанная на Python, которая выполняет геометрические вычисления. Этот проект представляет расчета площади и периметра стандартных плоских геометрических фигур.

*Цель разработки*: описание в отдельном файле площади и периметра треугольника, прямоугольника. Это позволит использовать функции библиотеки в сторонних проектах через простой импорт.

### Структура репозитория:
* `geometric_lib` — корневая директория.
* `rectangle.py` — функции для работы с прямоугольниками.
* `triangle.py` — функции для работы с треугольниками.

### Математические модели:
* **Прямоугольник** —  площадь рассчитывается по формуле $S = a \cdot b$, периметр по $P = 2 \cdot (a + b)$.
* **Треугольник** —  площадь рассчитывается по формуле $S = (a \cdot h)/2$, периметр по P = a + b + c.

## Описание функций с примерами вызова

### 1. Прямоугольник (rectangle.py)
*Функция расчёта площади* — `area(a, b)`

**Описание:** Вычисляет площадь прямоугольника по двум его сторонам.

**Параметры:**
* `a` (int/float): длина первой стороны прямоугольника.
* `b` (int/float): длина второй стороны прямоугольника.

**Возвращаемое значение:** 
* `area` (int/float): площадь прямоугольника (произведение a и b).

**Пример вызова:**
```python
from rectangle import area

print(area(3, 2))
```

*Функция расчёта периметра* — `perimeter(a, b)`

**Описание:** Вычисляет периметр прямоугольника по двум его сторонам.

**Параметры:**
* `a` (int/float): длина первой стороны прямоугольника.
* `b` (int/float): длина второй стороны прямоугольника.

**Возвращаемое значение:** 
* `perimeter` (int/float): периметр прямоугольника (удвоенная сумма a и b).

**Пример вызова:**
```python
from rectangle import perimeter

print(perimeter(3, 2))
```

### 2. Треугольник (triangle.py)
*Функция расчёта площади* — `area(a, h)`

**Описание:** Вычисляет площадь треугольника по длине его основания и высоте.

**Параметры:**
* `a` (int/float): длина основания треугольника.
* `h` (int/float): высота, опущенная на это основание.

**Возвращаемое значение:** 
* `area` (int/float): площадь треугольника (произведение a и h, поделённое на 2).

**Пример вызова:**
```python
from triangle import area

print(area(3, 8))
```

*Функция расчёта периметра* — `perimeter(a, b, c)`

**Описание:** Вычисляет периметр треугольника по трём его сторонам.

**Параметры:**
* `a` (int/float): длина первой стороны треугольника.
* `b` (int/float): длина второй стороны треугольника.
* `c` (int/float): длина третьей стороны треугольника.

**Возвращаемое значение:** 
* `perimeter` (int/float): периметр треугольника (сумма a, b и c)

**Пример вызова:**
```python
from triangle import perimeter

print(perimeter(3, 4, 5))
```
